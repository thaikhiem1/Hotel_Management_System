# Invoice Components

Các component quản lý hóa đơn thanh toán, chuẩn hóa 100% theo Database.md

## Components

### 1. InvoiceModal
Modal xuất phiếu hóa đơn thanh toán khi khách hàng checkout.

**Props:**
- `room`: Thông tin phòng đang checkout
- `rentalReceipt`: Thông tin phiếu thuê (rental_receipts table)
- `bookingDetail`: Chi tiết đặt phòng (booking_details table)
- `services`: Danh sách dịch vụ đã sử dụng (booking_detail_services table)
- `isOpen`: Trạng thái modal
- `onClose`: Callback đóng modal
- `onConfirm`: Callback xác nhận thanh toán

**Features:**
- Hiển thị đầy đủ thông tin khách hàng, nhân viên, phòng
- Tính toán tự động: tiền phòng + tiền dịch vụ = tổng thanh toán
- Giao diện responsive, hỗ trợ dark/light mode
- Xác nhận thanh toán và tạo hóa đơn

**API Integration:**
```javascript
// POST /api/invoices
{
  rental_receipt_id: number,
  employee_id: number,
  invoice_date: string (ISO date),
  total_amount: number,
  payment_status: 'PAID'
}
```

### 2. InvoiceCard
Card hiển thị tóm tắt thông tin hóa đơn trong danh sách.

**Props:**
- `invoice`: Thông tin hóa đơn (invoices table with relations)
- `onView`: Callback xem chi tiết hóa đơn
- `onPrint`: Callback in hóa đơn

**Features:**
- Hiển thị trạng thái thanh toán (PAID/UNPAID)
- Thông tin khách hàng, phiếu thuê, nhân viên
- Actions: Xem chi tiết, In hóa đơn
- Giao diện card với hover effects

### 3. InvoiceDetailModal
Modal xem chi tiết hóa đơn đã tạo.

**Props:**
- `invoice`: Thông tin hóa đơn đầy đủ
- `isOpen`: Trạng thái modal
- `onClose`: Callback đóng modal
- `onPrint`: Callback in hóa đơn

**Features:**
- Hiển thị đầy đủ thông tin hóa đơn đã thanh toán
- Chi tiết phòng, dịch vụ, khách hàng, nhân viên
- Tổng kết thanh toán
- In hóa đơn

## Usage

### Trong DashboardPage (Checkout Flow)
```jsx
import { InvoiceModal } from '@/components/invoice';

const DashboardPage = () => {
  const [isInvoiceModalOpen, setIsInvoiceModalOpen] = useState(false);
  const [invoiceData, setInvoiceData] = useState(null);
  
  const handleCheckout = async (room) => {
    // Fetch invoice data từ API
    const data = await fetchInvoiceData(room.id);
    setInvoiceData(data);
    setIsInvoiceModalOpen(true);
  };

  const handleInvoiceConfirm = async (invoiceResult) => {
    // Gọi API tạo hóa đơn
    await createInvoice(invoiceResult);
    // Refresh danh sách phòng
    refreshRooms();
  };

  return (
    <>
      {/* ... */}
      <InvoiceModal
        room={selectedRoom}
        rentalReceipt={invoiceData?.rentalReceipt}
        bookingDetail={invoiceData?.bookingDetail}
        services={invoiceData?.services}
        isOpen={isInvoiceModalOpen}
        onClose={() => setIsInvoiceModalOpen(false)}
        onConfirm={handleInvoiceConfirm}
      />
    </>
  );
};
```

## Database Schema

### invoices table
```sql
CREATE TABLE invoices (
    invoice_id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    invoice_date DATE NOT NULL,
    total_amount NUMERIC(18,2) NOT NULL,
    employee_id INTEGER NOT NULL,
    rental_receipt_id INTEGER NOT NULL UNIQUE,
    payment_status VARCHAR(20) NOT NULL, -- 'UNPAID' | 'PAID'
    
    CONSTRAINT fk_invoice_employee
        FOREIGN KEY (employee_id)
        REFERENCES employees(employee_id),
    
    CONSTRAINT fk_invoice_rental_receipt
        FOREIGN KEY (rental_receipt_id)
        REFERENCES rental_receipts(rental_receipt_id)
);
```
